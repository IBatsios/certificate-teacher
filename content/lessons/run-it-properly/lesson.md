---
title: Run it like a real thing
---

The last lesson ended with an image of your own, `my-site:3`, signed with your token. You have run it with a `-p` you were told to type and not why. This lesson is the why, four times over: ports, volumes, environment variables, and networks, which are the four things every `docker run` and every Compose file is made of. Then the two things that separate a container somebody ran from one somebody would run for real: it does not run as root, and it can say whether it is working. Then the ending. Your own image, behind the nginx proxy from the certificates course, on https, with the certificate you made there. It is the moment the two courses stop being two courses.

You need Docker Desktop running, the `my-site` folder from the last lesson with `my-site:3` built from it, and a text editor. Step 6 needs a browser and the `my-certs` folder from the certificates course, with `localhost.crt` and `localhost.key` still in it, next to `my-site`; if that folder is gone, step 6 says what to do. If you use Git Bash on Windows, use PowerShell for this lesson, and step 2 says why.

Work through the steps in order, and tick each one when it is done. Your progress is saved as you go.
